# PyCitySchools

## Problem
District leaders need a clear read on school performance: spending, size, type (charter vs district), and test outcomes — without drowning in raw CSVs.

## What we built
A pandas analysis (`Starter_Code_Pandas/`) summarizing district and school metrics, spending bins, and size/type comparisons.

Notable findings from this run:
- Higher spending did not cleanly track with higher scores
- Charter schools tended to outperform district schools on overall passing
- Medium schools led large schools on overall passing rates

## How to run
```bash
pip install pandas jupyter
jupyter notebook Starter_Code_Pandas/*.ipynb
```

## Stack
Python · pandas · Jupyter
